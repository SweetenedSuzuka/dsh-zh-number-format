# DSH中文计数插件

DeepSeek Harness的界面默认沿用英语三位分节的计数方法，且未使用中文的规范用词，如：
- 12345个词元显示为「12.3K」
- 长数字按三位一组加逗号
- 模型处理内容的最小单位写作「token」。

本插件可以使得 DSH 的界面按标准中文的用词与计数方式显示：
- 同一组词元显示为「1.2万」
- 速度单位显示为「词元/秒」
- 长数字不加逗号分组

> 「词元」是全国科学技术名词审定委员会规定的中文用词，指数据、信息或物理对象的一种符号化表示或最小处理单元，正对应语言模型中的「token」。  
> 由于「token」在英语里是一词多义的（例如密码学中指「令牌」），因此插件只对表达「语言模型计算的最小处理单元」这个意思的「token」进行替换。

## 功能

- **将英语式三位分节改为符合中文标准的四位分级**：
  - 小于一万直接显示：「9K」→「9000」
  - 一万起按「万」「亿」「兆」（兆取 10^12）保留一位小数（四舍五入）：
    - 「12345」→「1.2万」
    - 「99999999」→「1亿」（9999.99万末位进位）
  - 对于详情弹窗提供完整数字的位置（如对话底部的用量标签），标签按完整数字取一位小数：「1.2M」→「123.5万」
- **去掉三位分节的逗号分组**：
  - 「1,234,567」显示为「1234567」
- **「token」改称「词元」**：
  - 「tok/s」→「词元/秒」
  - 「TPS」→「词元/秒」
  - > 命令行里指斜杠命令的「token」保持不变。

## 关于转换精度问题的额外说明

如对话底部用量等位置的数字，DSH 在把数值提交到前端界面之前，已经先按三位分节四舍五入到了小数点一位，如`1234567`个词元在提交给前端界面时是`1.2M`。  
这种情况下，插件只能获取这种已经损失精度的数值，以上面这个例子而言，只能转换为`120万`。  
但是在点击了底部用量的详细之后，弹出的窗口中会显示具体的数值，此时插件会根据这个数值重新计算准确值，例如上面的例子中会把数值改为`123.5万`。

## 工作原理

- 在前端界面增加注入，使用四位分级的方式重写三位分节的数字，并去除分号，将表示语言模型最小处理单位的「token」替换成「词元」
- 删除无参数的 `Number.prototype.toLocaleString` 的分组行为（原本用于账户余额整数部分的格式化）。

插件会作用于前端界面的全部文本，因此凡是在前端界面处理的文字都会被插件处理，虽然按照涉及插件只对 DSH 本身的计数与用词有效，但也不排除将其它插件前端的文字替换的可能，例如「token」可能会被替换为「词元」。

## 安装方法

- 使用 npm 安装：
  - 直接在 DeepSeek Harness 桌面版的安装插件窗口中填写 `dsh-zh-number-formatdsh` 即可安装
  - 或者使用命令行执行：
    - 桌面版：`plugin --profile desktop add dsh-zh-number-formatdsh@latest`
    - Web端：`plugin --profile web add dsh-zh-number-formatdsh@latest`
    - 其它配置：`plugin --profile <profile> add dsh-zh-number-formatdsh@latest`
- 手动安装为本地插件：
  - 把代码目录下载到 DSH profile 的 `vendor/` 目录，再在该 profile 的 `pnpm-workspace.yaml` 里把它列为 workspace 成员，随后在 `package.json` 中把写入 `workspace:*` 以来，并加入 `dsh.profile.bundles`。
